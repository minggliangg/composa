## "Reset to original size" — beside "Reset aspect"

Adds a second reset action that sets a layer's rendered `width`/`height` back to its source `naturalWidth`/`naturalHeight`, **recentering on both axes** (the center point stays fixed) — a deliberate parallel to the existing `resetLayersAspect`, which holds width and recenters vertically. Same store seam, same history behavior (one undo step), same predicate/disabled-button pattern, parallel unit tests.

Behavior, state schema (no new fields), component APIs (additive only), icon shapes (new sibling icon, existing ones untouched), and every existing `data-testid` are preserved. All 190 unit + 12 e2e specs stay green.

### 1. Store action — `src/state/compositionStore.ts`

Add `resetLayersToOriginalSize: (ids: string[]) => void` to the `CompositionStore` interface (mirroring `resetLayersAspect`'s interface docstring style), then implement it directly after `resetLayersAspect` (after line ~258). Implementation mirrors reset-aspect's filter + route-through-`updateLayersTransform` pattern:

```ts
resetLayersToOriginalSize: (ids) =>
  get().updateLayersTransform(
    get()
      .layers.filter(
        (l) =>
          ids.includes(l.id) &&
          l.naturalWidth > 0 &&
          l.naturalHeight > 0,
      )
      .map((l) => {
        const newW = l.naturalWidth
        const newH = l.naturalHeight
        // Hold the center on both axes (parallel to reset-aspect's vertical
        // recenter). Top-left shifts so the center point stays put.
        const x = l.x + (l.width - newW) / 2
        const y = l.y + (l.height - newH) / 2
        return { id: l.id, patch: { width: newW, height: newH, x, y } }
      }),
  ),
```

- Filters layers with valid natural dims (guards div-by-zero, skips no-dim layers — same guard as reset-aspect).
- One `updateLayersTransform` call = one `set()` = one undo step (no gesture wrapping needed; matches reset-aspect).
- Patches route through `quantizePatch`, so `x`/`y`/`width`/`height` snap to the half-pixel grid. Since `naturalWidth`/`naturalHeight` are integers and `x`/`y` deltas are half-integer-safe given integer dims, snapping is effectively a no-op on size but still applies to the derived position — keeping it consistent with the rest of the transform seam.

### 2. Predicate — `src/panels/RightPanel/transformValidation.ts`

Add `isLayerResized(layer: Layer): boolean` beside `isLayerDistorted`. Returns `true` when the layer's rendered dims don't match its natural dims:

```ts
/**
 * Has a layer's rendered size drifted from its source pixel dimensions? Unlike
 * ratio, size drifts any time a layer is scaled (drag-resize, typed W/H) — so
 * this is true for almost every overlay (uploads default to ~45% of the canvas,
 * not 1:1). The reset-to-original-size button stays inert only when the layer
 * already renders at exactly its source pixel dims.
 */
export function isLayerResized(layer: Layer): boolean {
  if (layer.naturalWidth <= 0 || layer.naturalHeight <= 0) return false
  return layer.width !== layer.naturalWidth || layer.height !== layer.naturalHeight
}
```

- Exact comparison (not epsilon): natural dims are integers from the WASM probe, and the half-pixel grid means a layer genuinely at natural size has integer width/height. Epsilon would leave the button perpetually enabled.
- Returns `false` for no-dim layers (button stays inert — same as `isLayerDistorted`).
- Note: this will be `true` for nearly every overlay in practice (uploads scale to 45% of canvas, not 1:1), so the button is usually enabled — which is the honest state ("this layer isn't at its original size").

### 5. Tests — parallel to the reset-aspect coverage

**`tests/unit/compositionStore.test.ts`** — add a `describe('resetLayersToOriginalSize (revert to source pixel dimensions)', ...)` block mirroring all 7 reset-aspect cases, adapted to the new math:
1. Restores a resized layer to `naturalWidth`×`naturalHeight`, recentered on both axes (e.g. natural 100×100 rendered 200×200 at (50,50) → 100×100 at (100,100), center held at (150,150)).
2. Near-no-op when already at natural size (renders 100×100 at natural 100×100 → unchanged).
3. Snaps the derived x/y to the half-pixel grid (construct a case where `(width - naturalWidth) / 2` is non-integer, e.g. width 201 natural 100 → x delta 50.5).
4. Reverts each layer independently in a multi-select.
5. Ignores ids that don't resolve to a layer.
6. Skips layers with zero natural dimensions (no throw, untouched, isDirty stays false).
7. Idempotent: calling twice yields the same geometry.
